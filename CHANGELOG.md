# Changelog

## 0.4.0 - 2026-09-10

- Align the bar widget and popup structure with Omarchy's publishing contract.
- Add keyring-backed one-time browser authentication.
- Add filtered song, album, and artist search plus playlist browsing.
- Add private mpv playback with play, pause, seek, next, previous, shuffle, and
  repeat controls.
- Bound long result lists in a bordered scrolling container.
- Reduce idle polling and improve first-track startup.
- Add session cleanup, runtime-directory checks, and regression tests.
